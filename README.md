This plugin allows you to rebind the middle mouse button to an additional button for free camera movement. Press the configured key and then move your mouse to freely move the camera.

## Camera key speed
This plugin also lets you adjust the speed at which the keyboard camera keys move including a customizable on-screen text indicator (independent from the free-look camera). The camera key options are grouped under **Use camera key configuration**; while that is off the plugin leaves the arrow key camera completely alone.
